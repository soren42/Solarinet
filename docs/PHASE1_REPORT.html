Verification

Built two independent ways — direct gcc and the project's CMake/ctest — both with -std=c99 -Wall -Wextra -Wpedantic -Werror=implicit-function-declaration, zero warnings.

100% tests passed, 0 tests failed out of 4 suites (31 assertions-level tests)
  test_crypto   9 tests   FNV/CRC/SHA against published vectors, CN parsing
  test_tlv      5 tests   writer/reader symmetry, truncation, buffer-full
  test_frame   11 tests   byte-exact golden header, build/parse, CRC & magic guards
  test_msg      6 tests   client/monitor/hello/control/error round-trips, fwd-compat

The golden-frame fixture (tests/fixtures/golden_frames.h) is a hand-computed 32-byte header image — independent of the code under test — so it pins the wire format for SCP_PROTO_VERSION 1 regardless of host endianness, exactly as the §14 mandate requires.

Three bugs were caught by the tests and fixed: the reflected CRC-32 polynomial was mistyped (0xEDB88820 → 0xEDB88320), the FNV-1a-64 offset basis was missing a digit, and certificate-CN extraction didn't trim a leading space. All three now verify against reference vectors.

Build it yourself

make test        # configure, build, run ctest (zero external deps)
# or directly:
cmake -S . -B build -DSOLARI_BUILD_TESTS=ON
cmake --build build && ctest --test-dir build --output-on-failure
