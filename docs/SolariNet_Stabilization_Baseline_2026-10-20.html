3. Priority sequence and executable gates

  1. Contain and authenticate. Complete F-02/F-03/F-13/F-14; test viewer, operator, origin, token, and offline states in a real browser. Cut over the PHP/host queue only after the uid split and a rehearsed rollback. A green route test alone is insufficient.
  2. Make state durable. Close F-08 event delivery, F-10 convergence truth, F-12 migration ledger, and F-17 validated DNS apply. Inject broker loss and consumer crashes against disposable targets. No event may be acknowledged before its required target state is durable.
  3. Prove identity and lease behavior. Bind certificates to node IDs and roles (F-01), move long scans off the lease loop (F-05), then exercise two-server lease and bind-failure cases (F-09).
  4. Integrate deliberately. Advance RackWire's pin, preserve its standalone SQLite/discovery boundary, and test the SolariNet iframe/API/SoR commit boundary. Add shared maturity, provenance, freshness, and entity navigation as specified by I0-I4 in the August workflow.
  5. Publish only after evidence. Produce self-contained HTML user/developer manuals and parallel Letter PDFs for each app; review release artifacts and run restore/rollback drills. Merge to Forgejo main, mirror GitHub, deploy staged artifacts, verify actual services, then tag matching releases.
