# SolariNet — brand & interface standards

**Canonical:** `SolariNet Interface Guide Rev2.html` (Letter format, dark/light).
A corrective pass over the generated first identity, produced with the dashboard
screenshots in hand. It assigns every colour, face, and glyph exactly one job.

Served at **`https://akoria.net/brand/`**.

## The keystone rule (Rev 2 §02)
A hue that reports condition may not also decorate the interface. Brand/chrome/
links use **Signal Azure `#22B8F0`**; green/amber/red/violet/slate are reserved
for **status only**. Plus the *quiet-healthy* principle (§06): healthy renders as
hairline structure — no fill, no glow — so faults are the only colour on screen.

## Implementation
Rev 2 §16 is an ordered change list for the dashboard (colour architecture,
quiet-healthy tiles, self-hosted Plex Sans + Mono, the 14 interface fixes) and a
new mark (§07–09: azure, no baked-in status red). Tracked as dashboard work.
